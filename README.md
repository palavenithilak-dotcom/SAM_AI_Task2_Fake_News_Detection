# SAM AI Task 4 - Fake News Detection

A Streamlit NLP + Machine Learning demo that classifies a news statement as Real or Fake.

## Features
- NLP preprocessing with TF-IDF
- Logistic Regression classifier
- Train/test split
- Accuracy and classification report
- Confusion matrix visualization
- Prediction confidence
- Interactive news-text prediction

## Run
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

> The bundled dataset is intentionally small for a quick demonstration. For a portfolio-quality model, replace it with a larger labeled real/fake news dataset.
